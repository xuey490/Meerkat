这些变量**没有**仓库里单独的「环境变量配置文件」（没有 `webserver/.env` 之类）。程序在启动时从**当前进程的环境**里读，逻辑在 `webserver/internal/webapp/app.go` 的 `LoadConfig`：环境变量有值就**覆盖** `configs/webserver.yaml` 里对应字段。

## 实际可以怎么设

### 1. 直接写在 YAML（本机开发最常见）

文件：**`webserver/configs/webserver.yaml`**

| 环境变量 | YAML 里对应项 |
| --- | --- |
| `WEBSERVER_JWT_SECRET` | `jwt.secret` |
| `WEBSERVER_ADMIN_PASSWORD` | `bootstrap_admin_password` |
| `MONITOR_POSTGRES_PASSWORD` | `postgres.password` |
| `MONITOR_INFLUX_TOKEN` | `influx.token` |

不设环境变量时，就用 YAML 里的值。你现在的 `webserver.yaml` 里已经有 `jwt.secret`、`postgres.password` 等，所以本机只跑 exe、不 export 变量也能起来。

### 2. 启动前在当前终端里设（README 里 `go run` / 手动跑 exe 的方式）

PowerShell 示例（只在**这个窗口**里有效，关掉就没了）：

```powershell
$env:WEBSERVER_JWT_SECRET = "你的随机串"
$env:WEBSERVER_ADMIN_PASSWORD = "Monitor123!"
$env:MONITOR_POSTGRES_PASSWORD = "123456"
$env:MONITOR_INFLUX_TOKEN = "<Influx write token>"
.\webserver.exe -config .\configs\webserver.yaml
```

Linux/macOS 用 `export WEBSERVER_JWT_SECRET=...` 再启动进程，同理。

### 3. 一键脚本里**只自动设了一部分**

**`scripts/windows/server/start.ps1`**（仓库根目录执行）：

- **`WEBSERVER_ADMIN_PASSWORD`**：若没设，脚本里会写成 `Monitor123!`，再 `Start-Process` 拉起 webserver（子进程会继承）。
- **`MONITOR_INFLUX_TOKEN`**：若没设，会从 `server/configs/server.local.yaml` 或 `webserver/configs/webserver.yaml` 里读 `influx.token` 填到环境变量（主要给 Collector / Influx 用；webserver 子进程也会继承）。

脚本**不会**自动设 `WEBSERVER_JWT_SECRET` 和 `MONITOR_POSTGRES_PASSWORD`，这两项要么写在 **`webserver/configs/webserver.yaml`**，要么你在跑脚本**之前**在同一个 PowerShell 里 `$env:... = ...`。

Linux 对应 **`scripts/linux/server/start.sh`**：默认只 export `WEBSERVER_ADMIN_PASSWORD`（未设则为 `Monitor123!`）。

### 4. 生产 / Linux 服务

文档里写的是自己建环境文件，例如 **`/etc/monitor-webserver/env`**，在 systemd 里 `EnvironmentFile=...`，内容类似：

```ini
WEBSERVER_JWT_SECRET=...
WEBSERVER_ADMIN_PASSWORD=...
MONITOR_INFLUX_TOKEN=...
```

仓库里**没有**提交这个文件，需要你在服务器上新建。

Windows 长期生效也可以：**系统设置 → 环境变量**（用户/系统），或任务计划程序 / NSSM 启动项里配置环境变量。

---

**小结**：没有固定「在哪个文件设环境变量」——要么改 **`webserver/configs/webserver.yaml`**，要么在**启动 webserver 的进程**上设环境（终端、`start.ps1` 运行前的会话、systemd 的 env 文件、Windows 系统环境变量）。`WEBSERVER_JWT_SECRET` 和 `MONITOR_POSTGRES_PASSWORD` 在本仓库脚本里**没有**默认值，本机一般直接写在 `webserver.yaml` 最省事。
